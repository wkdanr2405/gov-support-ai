# 08. 발표 덱과 구현이 다른 부분

구현하면서 덱과 달라지는 내용을 여기에 적고, 발표 전에 덱 또는 구현 중 하나를 맞춘다.

|---|---|---|---|

## 최종 발표 PPT 제작 시 반영할 것 (사용자 결정 11/11)
덱을 지금 고치지 않는다. **최종 발표 PPT를 만들 때** 아래를 한꺼번에 반영한다. (기준 덱: `docs/deck/..._최종_v3`)
1. 수치: 가상 기업 첫해 감면액 6,800만 원(통합고용 1,800만 + 연구·인력개발비 5,000만), 3년째 통합고용 4,400만 원. 옛 값 8,750만 원·1,450만/850만은 쓰지 않는다.
2. 14번 향후 발전: 가상 서류 업로드를 구현했으면 "NOW"로 옮기고, 실제 OCR·실시간 반영은 향후로 둔다.
3. 법령 확인 현황: 19건 중 18건 확인 (남은 1건은 "제조업과 유사한 사업" 범위). 확인 못 한 값은 확정처럼 보이지 않는 설계 원칙의 사례로 소개.
4. 11/11 정정 사례(발표 소재): 별표 1·3 전수 대조로 업종별 매출 기준 오류 7건 정정(음료 C11 800억, 수리업 C34 600억, 농림어업 A 1,000억, 숙박음식 I 400억 / 소기업 석유정제 140억, 도소매 60억, 하수·폐기물 40억).
5. 기능 추가분: 창업감면 지역 구분 자동화(시·군·구 선택), 공시대상기업집단·소비성서비스업 제외 판정, 전문가 연결(가상 전문가·상담 전달 자료 1페이지 PDF), 공고 품질 필터(임대·행사·타 지역·타 업종 제외).
6. 화면 디자인이 Shopifi 풍(크림 바탕·검정 상단 띠·Do Hyeon 제목)으로 바뀌었으므로 덱 스크린샷은 배포 화면으로 새로 찍는다.
7. 건수 표기: pytest 163건(최신 값으로 다시 확인), 공고 저장본 K-Startup 196건·기업마당 300건(12월 초 갱신 시 수정).

## 전문가 연결 — 향후 발전 슬라이드 문안 (최종 PPT용)
**지금(시연):** 가상 전문가 6명(세무사 4·회계사 2)을 SQLite 데이터베이스에 담고, 분야·소재지·업종 점수로 추천, 전문가 등록 신청→운영자 승인→상담 요청→전문가의 고객 상담 요청 확인까지 한 흐름을 화면으로 시연 (저장·발송 없음, 접속 동안 메모리에만 존재).
**향후(실서비스):** ① 협약 전문가 모집과 자격번호 공식 조회(한국세무사회·한국공인회계사회) ② 소개 수수료 구조의 세무사법·회계사법 검토 ③ 개인정보 동의·암호화 저장·로그인 ④ 이메일·문자 실제 발송 ⑤ 상담 후 평가를 추천 순위에 반영.
