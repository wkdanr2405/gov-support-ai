# 08. 발표 덱과 구현이 다른 부분

구현하면서 덱과 달라지는 내용을 여기에 적고, 발표 전에 덱 또는 구현 중 하나를 맞춘다.

| 덱 슬라이드 | 덱의 내용 | 구현 | 조치 |
|---|---|---|---|
| 9번 이원화 분석 엔진 (Track B) | 공고문을 임베딩해 DB 구축 | 조건 필터 + 키워드 점수 + 임베딩(의미 유사도) 혼합 점수로 구현됨 (11/2). 덱 문구와 대체로 일치하나 DB 구축은 파일 저장 | 덱에 "조건 필터 후 키워드·의미 혼합 점수"로 맞춰 표기 |
| 6·9번 | 통합고용 청년 1인당 1,450만 / 청년 외 850만, 연 감면액 8,750만 원 | **2026년 귀속은 연차별 금액이 다름** (수도권 중소 청년 700/1,600/1,700만, 청년 외 400/900/1,000만, 법 제29조의8 원문 확인). 가상 기업 첫해 통합고용 1,800만 + R&D 5,000만 = 6,800만, 3년째 통합고용 4,400만 (`05-tax-rules-spec.md`) | 덱의 계산 박스와 8,750만 원, 시나리오 막대(1,450/2,900/4,350)를 새 수치로 교체 | **→ v3 반영 완료 (11/2)**
| 6번 Scene 2 | 청년 채용 인원별 연 절감액 막대 (0/+1/+2/+3명) | 연차별(1·2·3년차) 금액으로 표시 | 그래프 구성 변경 |
| 8번 기능① | 입력 항목에 사업자등록번호 | 기업 규모 판정용 입력(자산·매출·독립성)과 가상 서류 업로드 시연이 추가됨 | 덱에 규모 판정 단계 추가 | **→ v3 반영 완료**
| 7번 프로세스 / 6번 UI | 전문가 연결 | 화면 시뮬레이션만 (실제 발송·매칭 없음) | 발표에서 "프로토타입 범위"로 설명 |
| 14번 향후 발전 | OCR, 실시간 반영 | **서류 업로드 시연(가상 샘플 한정)은 5주차에 선택 구현**, 실제 서류 OCR·실시간 반영은 구현 안 함 | 구현되면 "NOW"로 이동, 아니면 변경 없음 |
