# 07. 사용자가 직접 해야 할 일

키는 본인 계정으로 발급해야 합니다. 발급한 키는 **채팅이나 코드에 붙여넣지 말고** `.env` 파일 또는 배포 서비스의 secrets에만 넣으세요.

## 결정된 사항 (2026-11-01)
- 발표 방식: **배포 URL 제출** (교수님 과제 요구사항은 따로 정해진 것이 없어 자유롭게 제작)
- 기업 규모 판정: 규칙 엔진으로 계산 + 가상 서류 업로드 시연(4~5주차, 시간이 부족하면 "향후 발전"으로)
- Python 설치는 필수가 아님 (개발은 Claude Code 작업 환경에서 진행)

## A. 개발 환경 (1주차)
- [x] Python 설치 → **불필요** (작업 환경에 이미 있음). 내 PC 실행은 선택 사항
- [ ] (5주차) GitHub 계정 만들기 + 비공개 저장소 1개 → 배포 서비스 연결용

## B. 키 발급 (1~2주차)
- [x] (11/2 완료) **공공데이터포털(data.go.kr)** 회원가입 → "창업진흥원_K-Startup 조회서비스" 활용신청 → 발급된 인증키 복사
  - `.env`의 `DATA_GO_KR_API_KEY=` 뒤에 붙여넣기 (배포 시에는 secrets에)
- [x] (11/2 신청·승인 완료, 데이터 수집은 PC 실행 필요) **기업마당(bizinfo.go.kr)** 정책정보 개방(Open API) 안내에서 인증키 신청 방법 확인 → 발급되면 `BIZINFO_API_KEY=`에 입력
  - 신청 절차를 확인하지 못했습니다. 화면에 나온 안내 문구를 Claude에게 알려 주세요.
- [ ] **Claude API 키** 발급 (4주차 해설을 실제 AI로 쓰려면 필요. 없으면 기본 문장으로 동작) (결제수단 등록이 필요할 수 있음, 최소 충전액은 가입 화면에서 확인) → `ANTHROPIC_API_KEY=`에 입력

## C. 알려 주실 것
- [x] 발표 방식: 배포 URL
- [x] 교수님 요구사항: 별도 지정 없음 (자유 제작)

## D. 키가 없을 때
키가 없어도 샘플 데이터와 저장본으로 화면과 계산 기능은 개발할 수 있습니다. 실제 API 연동만 키 발급 후에 확인합니다.

## E. 배포 URL 주의 (공개 주소)
- 가상 기업 데이터와 가상 서류 샘플만 사용합니다. 실제 사업자 정보·급여 자료를 올리지 않습니다.
- 사용자 입력은 저장하지 않습니다 (세션 안에서만 처리).
