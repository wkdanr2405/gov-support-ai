# 화면 디자인 규칙 (11/7 적용)

기준: 사용자가 제시한 "사진은 말하고 화면 장치는 조용하다"는 상거래 디자인 가이드(검정·흰색·옅은 회색, 알약 버튼, 평평한 카드).
브랜드 이름·로고·전용 글꼴은 쓰지 않고, 색·모양·간격 규칙만 우리 서비스에 맞게 옮겼다.

## 그대로 옮긴 것
| 규칙 | 우리 화면 |
|---|---|
| 색은 검정(#111)·흰색·옅은 회색(#f5f5f5)만. 유채색은 의미가 있을 때만 | 성공 초록(#007d48)은 "금액 계산됨"·중소기업 해당 상자, 오류 빨강(#d30005)은 오류 상자에만 |
| 주 버튼은 검정 알약(모서리 30px, 높이 48px) | 해설 만들기, PDF 내려받기, 상담 요청 |
| 입력칸은 옅은 회색 + 둥근 모서리(24px), 선택하면 검정 2px 테두리와 옅은 회색 후광 | 모든 입력칸·선택창 |
| 카드는 평평하게: 모서리 직각, 그림자 없음, 1px 머리카락 선(#cacacb) | 요약 띠, 공제·감면 카드, 펼침 상자 |
| 탭은 선택된 탭에 검정 2px 밑줄 | 입력·결과 탭 |
| 글씨는 아주 큰 제목과 작은 본문의 극단적 대비 | 맨 위 제목 3rem(굵게), 본문 1rem |
| 안내 상자는 평평한 회색 바탕 + 왼쪽 색 줄 | 중소기업 판정, 면책 문구 등 |

## 우리에 맞게 바꾼 것
- 원본은 사진 위에 큰 글자를 얹는다. 우리는 사진이 없어서 검정 바탕에 흰 큰 글자만 쓰는 안내 띠로 대신했다.
- 원본의 "할인가 빨강"은 쓰지 않는다. 금액은 검정 굵은 글씨로만 강조한다.
- 원본은 영문 대문자 제목이다. 한글에는 대문자가 없어서 굵기와 크기 대비로만 표현했다.
- 원본의 전용 글꼴(Nike Futura ND, Helvetica Now)은 상용이라 쓸 수 없다. 대체 글꼴: 화면 UI는 Inter, 맨 위 큰 제목(웹)과 PDF 제목·큰 금액은 Do Hyeon(도현)을 쓴다. 모두 오픈소스(SIL OFL)이고, 후보 7종 중 사용자가 11/7에 선택했다. PDF 본문은 나눔고딕(한글 글꼴)이다.

## 구현 위치
- `.streamlit/config.toml` 테마(주 색, 배경, 둥근 정도), `app.py` 맨 위 `<style>` 블록(세부 모양).
- 면책 문구·"가상 기업 기준 예시" 표시 위치는 바꾸지 않았다 (프로젝트 절대 규칙 3·8).

## PDF 리포트 (같은 규칙)
- 맨 위 검정 띠에 흰 제목, 바로 아래 "첫해 예상 감면액"을 큰 숫자(Do Hyeon)로 보여 준다.
- 표 머리는 옅은 회색(#f5f5f5), 선은 머리카락 두께(#cacacb), 글자는 검정. 이전의 남색·진빨강은 없앴다.
- 면책 문구는 회색 상자 + 왼쪽 검정 줄. 여전히 1페이지에 모두 들어가야 하며(테스트로 확인), 서류 5개를 모두 넣어도 1페이지다.

## 웹 화면 디자인 변경 (11/7, Spotify 참고)
- 웹 화면만 어두운 테마로 바꿨다: 바탕 #121212, 카드·펼침 상자 #181818, 입력칸 #1f1f1f, 글자 흰색/은회색 #b3b3b3.
- 초록(#1ed760)은 버튼·선택 표시·탭 밑줄·"해당" 표시에만 쓴다. 오류 빨강 #f3727f, 경고 주황 #ffa42b, 안내 파랑 #539df5.
- 버튼은 초록 알약(검은 글자, 넓은 글자 간격), 입력칸은 어두운 알약, 카드는 모서리 8px과 무거운 그림자.
- Spotify 전용 글꼴(CircularSp)은 쓸 수 없어 Inter를 쓰고, 맨 위 제목만 Do Hyeon을 유지한다.
- PDF 리포트는 인쇄용이라 기존 흰 바탕 디자인을 유지한다.

## 웹 화면 디자인 재변경 (11/7, Shopifi 참고)
- 이유: 어두운 테마는 바탕과 카드가 모두 검정에 가까워 영역이 구분되지 않았다.
- 두 바탕을 섞지 않는다: 맨 위 띠만 순수 검정(#000), 작업 화면은 크림 바탕(#fbfbf5) + 흰 카드(#fff, 연한 선 #e4e4e7, 모서리 12px, 겹친 작은 그림자).
- 버튼은 알약만: 기본은 검정(눌리면 #3f3f46), 내려받기·상담 요청 보내기는 연두(#c1fbd4). 연두·피스타치오(#d4f9e0)는 면 색으로만 쓰고 글자 색으로 쓰지 않는다.
- 입력칸: 흰 바탕, 1px 연한 선, 모서리 8px, 선택하면 검정 선. 제목은 얇은(300) 글자, 본문은 Inter + `ss03`.
- Neue Haas Grotesk는 전용 글꼴이라 Inter 얇은 굵기로 대신하고, 맨 위 제목의 Do Hyeon은 쓰지 않는다. PDF는 기존 디자인 유지.
- (11/7 추가) 맨 위 제목은 Do Hyeon으로 되돌렸다. 작업 화면의 카드·입력칸·펼침 상자·탭 밑줄 테두리는 진한 회색(#8a8a90)으로 바꿔 크림 바탕과 확실히 구분한다.
