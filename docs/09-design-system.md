# 화면 디자인 규칙 (11/7 적용)

기준: 사용자가 제시한 "사진은 말하고 화면 장치는 조용하다"는 상거래 디자인 가이드(검정·흰색·옅은 회색, 알약 버튼, 평평한 카드).
브랜드 이름·로고·전용 글꼴은 쓰지 않고, 색·모양·간격 규칙만 우리 서비스에 맞게 옮겼다.

## 그대로 옮긴 것
| 규칙 | 우리 화면 |
|---|---|
| 색은 검정(#111)·흰색·옅은 회색(#f5f5f5)만. 유채색은 의미가 있을 때만 | 성공 초록(#007d48)은 "금액 계산됨"·중소기업 해당 상자, 오류 빨강(#d30005)은 오류 상자에만 |
| 주 버튼은 검정 알약(모서리 30px, 높이 48px) | 해설 만들기, PDF 내려받기, 상담 요청 |
| 입력칸은 옅은 회색 + 둥근 모서리(24px), 선택하면 검정 2px 테두리와 옅은 회색 후광 | 모든 입력칸·선택창 |
| 카드는 평평하게: 모서리 직각, 그림자 없음, 1px 머리카락 선(#cacacb) | 요약 띠, 공제·감면 카드, 펼침 상자 |
| 탭은 선택된 탭에 검정 2px 밑줄 | 입력·결과 탭 |
| 글씨는 아주 큰 제목과 작은 본문의 극단적 대비 | 맨 위 제목 3rem(굵게), 본문 1rem |
| 안내 상자는 평평한 회색 바탕 + 왼쪽 색 줄 | 중소기업 판정, 면책 문구 등 |

## 우리에 맞게 바꾼 것
- 원본은 사진 위에 큰 글자를 얹는다. 우리는 사진이 없어서 검정 바탕에 흰 큰 글자만 쓰는 안내 띠로 대신했다.
- 원본의 "할인가 빨강"은 쓰지 않는다. 금액은 검정 굵은 글씨로만 강조한다.
- 원본은 영문 대문자 제목이다. 한글에는 대문자가 없어서 굵기와 크기 대비로만 표현했다.
- 글꼴은 Inter(영문·숫자) + 시스템 한글 글꼴. 계산 금액의 자릿수가 또렷하게 보이는 것이 목적이다.

## 구현 위치
- `.streamlit/config.toml` 테마(주 색, 배경, 둥근 정도), `app.py` 맨 위 `<style>` 블록(세부 모양).
- 면책 문구·"가상 기업 기준 예시" 표시 위치는 바꾸지 않았다 (프로젝트 절대 규칙 3·8).
