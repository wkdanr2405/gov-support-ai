# 01. 무엇을 만드는가 (발표 덱 기준)

출처: `docs/deck/` 최종본 (16장)

## 한 줄 정의
스타트업·중소기업이 기업 정보를 입력하면 **세액공제 예상액 + 맞춤 정부지원사업 + 1페이지 리포트**를 한 번에 보여 주는 서비스. 기존 서비스가 한쪽만 다루는 것과 달리, 채용·투자 **전에** 받을 수 있는 혜택 총액을 미리 계산해 본다.

## 1단계(이번 프로토타입) 기능
1. **기업 프로필 입력**: 업종, 설립일(업력), 소재지, 매출액, 직전·당해 연도 상시근로자 수, 청년·장애인 근로자 수, R&D 지출액
2. **세액공제 계산 (Track A)**: 통합고용세액공제, 연구·인력개발비 세액공제. 고용 변동 시나리오별 절감액
3. **지원사업 매칭 (Track B)**: K-Startup·기업마당 공고에서 조건에 맞는 상위 N건. 매칭 점수·근거 키워드·D-day·담당부서 표시
4. **LLM 해설·리포트**: 적합 사유, 준비 서류, 유의사항, 감면 시나리오 요약. 대시보드 + 1페이지 PDF

## 화면 (덱 6번 슬라이드의 4개 장면)
- Scene 1 기업 정보 입력 → Scene 2 분석 대시보드(예상 연 감면액 카드, 청년 채용 인원별 절감 막대그래프, 추천 공고) → Scene 3 1페이지 리포트(요약·추천 공고·준비 서류·유의사항, PDF 다운로드) → Scene 4 전문가 연결(검토 요청 폼, 화면 시뮬레이션만)

## 시연용 가상 기업 (덱과 동일)
서울 소재 제조업(전자부품), 설립 2023-03-15(업력 3년), 매출 30억 원, 상시근로자 전년 10명 → 당해 13명(청년 2명·청년 외 1명 증가), R&D 지출 2억 원
→ 2026년 귀속 기준 첫해 예상 감면액 **6,800만 원** (통합고용 1,800만 + 연구·인력개발비 5,000만), 3차연도 통합고용 4,400만. (덱의 8,750만 원은 옛 규정 값 → `05-tax-rules-spec.md`, `08-deck-sync.md`)

## 이번 범위에서 제외
로그인·회원, 결제, 실제 전문가 매칭·이메일 발송, 실제 서류 OCR(가상 샘플 서류 업로드 시연은 선택 기능), 실시간 법령 반영, 임베딩 DB(시간이 남으면 추가), 연구·인력개발비 외 다른 공제 항목

## 법적 가이드 (덱 11·12번 슬라이드)
- 세무사법: 정보 제공·계산·시뮬레이션까지만. 신고 대행·세액 확정 표현 금지. 결과마다 면책 문구.
- 개인정보 보호법: 최소 수집, 목적 한정. 주민등록번호·개인 연락처는 받지 않는다. 사용자 입력은 저장하지 않는다.

## 기업 규모 판정 (결정 2026-11-01)
사용자가 규모를 직접 고르지 않는다. 자산총액·최근 3년 평균 매출액·업종·지분(독립성)을 입력하면 규칙 엔진이 중소기업 여부를 판정하고 근거를 보여 준다. 판정 기준표를 화면에 제시한다. 4~5주차에 가상 재무제표·4대보험 명부 샘플을 업로드하면 항목을 추출해 입력란을 채우는 시연을 선택 기능으로 붙인다. 판정 기준은 `data/tax_params/2026.yaml`의 `sme_test`(원문 대조 전).

## 전문가 연결 화면 (11/7 시연 완성형)
- 가상 전문가 후보 3명(`data/sample/experts.yaml`)을 합계에 들어간 공제·감면과 분야가 겹치는 순서로 보여 준다(규칙 기반, 추천 이유 표시).
- 계산 결과·준비 서류·추천 공고를 묶은 "상담 전달 자료"를 미리 보고 .txt로 내려받을 수 있다.
- 상담 요청을 보내면 시연용 접수번호와 진행 단계(요청 접수 → 전문가 검토 → 일정 안내 → 상담 → 신청 준비)를 보여 준다. 실제 전송·저장은 없다.
